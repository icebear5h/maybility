# Future Ideas

## AR/Spatial Computing

The 2D canvas grid system (dot grid background with pan/zoom) in the Ideas and Journal views is designed as a placeholder for a future AR/spatial computing interface. The canvas-based approach was chosen specifically to enable:

- Spatial positioning of nodes in 3D space
- Hand tracking / gesture-based navigation
- Head-tracked parallax and depth
- Passthrough mixed reality views
- Spatial anchoring of ideas and journal entries in physical space

The current 2D implementation mirrors the interaction patterns that would translate well to AR:
- Pan = head movement / walking
- Zoom = moving closer/further
- Node positioning = spatial placement
- Connections/arrows = spatial relationships
